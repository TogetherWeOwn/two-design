Design system

Every token and every component state in this system, rendered from tokens/two.css. No build step — open the file. This page is what built screens get reviewed against.

Colour values here are generated from the real token file by tools/build-preview.mjs, so this page cannot drift from what ships.

Colour

One palette, dark only. Sampled from TWO's own splash art — the brand runs violet to crimson with the green channel at zero, so even the greys are violet-cast. All 43 pairings this system uses are asserted in tools/check-contrast.mjs.

Grounds

  • canvas#0b0714 The page.
  • surface#130e20 Cards, panels, rows.
  • raised#1b1430 Hover, menus, skeletons.
  • violet#160750 One flat band per page. Never a gradient.

Lines — two, doing different jobs

  • line#2a2142 Decorative separation only. Under 3:1 on purpose.
  • line-strong#69607e Interactive control boundaries. Clears 3:1 on every ground.

Using line on an input border is the most likely accessibility bug in this build. Controls get line-strong.

Text — two, and that is the whole set

  • ink#edeaf4 Everything you read. 14.9:1 worst case.
  • ink-muted#9e96b5 Secondary. 6.3:1 worst case.
  • ink-disabled#686277 3:1. Contrast-exempt; we hold it anyway.

There is no third grey. Anything quieter than ink-muted is a size or weight change, not a colour change — a third grey would fail AA on canvas.

Presence, alert, focus

  • online#3bd07a A person is online. Matches Discord's convention.
  • alert#c47527 Errors and warnings. Burnt orange, not red — red beside a crimson button is indistinguishable at 14px.
  • focus#f3eeff Clears 3:1 on every ground and on a crimson fill.

Type

One family: Archivo, variable, self-hosted, OFL. It carries a width axis as well as a weight axis, which is why it is here — u-display gives us expanded signage lettering that echoes the logo lockup with no second font file.

Never u-display below 24px — expanded faces stop being legible. Never text-sm for paragraphs: small light-on-dark text loses legibility much faster than dark-on-light.

Radius & spacing

Nothing is rounder than 8px except a person's avatar, which is a circle. Soft 12–16px corners and pill buttons are the signature of every SaaS template; our mark is a chamfered shield, so the interface is hard-edged too.

Empty states

The most important components on this site. A new community site is mostly empty, and empty has to read as early, not abandoned. The hatch ground is lifted from the diagonal ruling in our own splash art — it says reserved. Budget: one hatched area per screen. Never an illustration, never a sad robot.

Nothing on the calendar yet.

Game nights get posted here first. Join the Discord and you'll see them before they land on this page.

Nothing scheduled right now.

The last one was three weeks ago. They usually go up about a week ahead.

You haven't RSVP'd to anything yet.

When you do, it shows up here.

Never the word "empty", "nothing found" or "no results" on its own. Say what happens next. Always exactly one action — an empty state with no way out is a dead end.

Error states

▲
Couldn't load the events. Refresh in a moment and it should be back.
▲
You'll need to be in the TWO Discord first. Join the server, then come back and log in.

role="status", not role="alert" — this did not interrupt anything the person was doing. Every message names the next action; "something went wrong" with no action is a shrug, not an error state.

The hero band

The violet is a flat band. There is no gradient anywhere on this site — see docs/BRAND.md for the argument, since our own logo is one.
